The .json documents in this folder, contain the result that each generation got. REFeREE only accepts English documents, therefore all of this evalauted results are of the /data folder, but it has been translated previously.

The start of the name is the same as the data from which it is taken, if it contains x-y, where x and y can be either c or s:
- c: original complex sentence to simplify
- s: simplified sentence, either original or by model

x-y: x is the sentences which where evaluated as if they where the complex ones, and y the sentences that where evaluated as the simplified versions

If the name conatins (), inside is the model that was used to translate the catalan text to english.
